Section 4: Trip-Level Mode Choice Models

This page presents the trip-level nested logit mode choice models estimated from the SEQ Household Travel Survey (HHTS). One model is fitted per activity purpose. These complement the tour-level destination and mode choice models (Stage 5, Section 3) and provide the trip-by-trip mode assignment used in the final synthetic activity plan.

Key socio-demographic extensions in this version: car licence (lic_da), full-time worker status (ft_da), industrial/trade worker type (ind_da), part-time worker (pt_tr), and public/health sector workers (pub_tr) are included alongside the standard vehicle ownership, age, income, and gender interactions. Crash risk (crash = log OD crash count + 1) enters motorised utilities as a safety deterrence term.
